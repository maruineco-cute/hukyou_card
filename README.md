# 布教カードメーカー

推し・飼い猫・自分を、交換カード風のプロフィールカードにして、縦長の画像(PNG)で保存できるメーカーです。
スマホのブラウザだけで使えます。

## できること

- サンプルをえらぶ(推し紹介 / 飼い猫 / 自己紹介)
- テーマ3種類(ゆめかわ / クール / サイバー)
- メンカラ(イメージカラー)を12色+自由な色から選ぶ
- タイトル・各枠の見出し・サブタイトルを書き換える
- メイン画像、ステータス(レーダーチャート)、おすすめ3件、大きなフリースペース
- ステッカーを選んで貼り、ドラッグで動かす
- 1800×3000pxの縦長PNGで保存

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | メーカー本体。画像や素材もこの1ファイルの中に入っています |
| `README.md` | この説明 |

ほかのファイルは必要ありません。

## スマホだけで公開する手順(GitHub Pages)

スマホのブラウザ(SafariやChrome)で github.com を開いて行います。
GitHubアプリでは、ファイルのアップロードができないので、ブラウザを使ってください。

1. github.com にログインし、右上の「+」から **New repository** を開く
2. Repository name に好きな名前を入れる(例: `fukyou-card-maker`)
3. **Public** を選び、**Create repository** を押す
4. できた画面の **uploading an existing file** のリンクを押す
5. `index.html` と `README.md` を選んでアップロードし、**Commit changes** を押す
6. 上のメニューの **Settings** → **Pages** を開く
7. **Source** を `Deploy from a branch` にして、Branch を `main` / `(root)` にし、**Save** を押す
8. 1〜2分ほど待つと、次のアドレスで開けるようになります

```
https://(あなたのユーザー名).github.io/(リポジトリ名)/
```

## 画像の保存について

- 「PNGを保存」を押すと、カードの画像ができます
- 自動で保存されないときは、できあがった画像を**長押し**して、iPhoneは「写真に追加」、Androidは「画像をダウンロード」を選んでください

## 使っているもの

- 文字: Google Fonts(Zen Maru Gothic / Mochiy Pop One / Shippori Mincho B1 / Zen Kaku Gothic New / DotGothic16)。インターネットにつながっていないと、ふだんの文字で表示されます
- ステッカー画像: 作者が用意した素材シートから切り出したものです。権利は作者が管理しています
